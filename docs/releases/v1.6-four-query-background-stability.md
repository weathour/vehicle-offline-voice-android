# 渝行智声 v1.6

发布日期：2026-08-26

## 软件信息

- 软件全称：渝行智声车载语音交互软件
- 版本号：v1.6（versionCode 16）
- Android 包名：`cn.edu.chd.yuxingvoice`

## 本版调整

- 正式语音范围收敛为车速、障碍物、协同模块和红绿灯四类只读查询；电量与规划轨迹点不再出现在界面、Vosk 语法或正式意图集合中。
- 正式 Redis 链路只读取四类查询所需的五个 Key，其中车速保留定位和独立车速两个来源。
- 启动真实语音服务后主界面自动退到后台。
- Release 版拒绝没有 `MAIN + LAUNCHER` 语义的直接 Activity 拉起，并保留最近 20 条界面生命周期记录。
- 后台服务改用启动 Intent 重投递，避免系统重建后误入模拟模式；录音流水线异常退出时最多自动恢复三次，并更新通知状态。
- `AudioRecord` 读取错误会进入明确的失败与恢复链路，不再静默结束监听。
- 按 Redis 当前返回值回答，不增加数据过期判断。红绿灯只回答灯色和置信度。

## 可问内容

1. 车速，例如“车速多少”“现在跑多快”。
2. 障碍物，例如“障碍物情况”“最近障碍物”。
3. 协同模块，例如“协同模块状态”“SAM 反馈”。
4. 红绿灯，例如“红绿灯什么状态”“信号灯状态”。
