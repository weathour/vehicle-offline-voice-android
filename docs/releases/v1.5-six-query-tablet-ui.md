# 渝行智声 v1.5

发布日期：2026-08-26

## 软件信息

- 软件全称：渝行智声车载语音交互软件
- 版本号：v1.5（versionCode 15）
- Android 包名：`cn.edu.chd.yuxingvoice`

## 本版调整

- 正式麦克风链路收敛为六类只读查询：车速、电量、障碍物、协同模块、规划轨迹点和红绿灯。
- Vosk 使用分词领域语法，规则解析器仅接受上述六类意图；覆盖常见错字、同音和近音识别结果，同时拒绝单个元音、单字、冲突问法及已移除主题。
- 识别结果只有在六类意图中形成唯一匹配时才回答；无法确定时提示重新表达，避免不同查询互相误判。
- 重做主界面信息层级，持续显示服务状态、车辆连接、最近识别文本和当前播报内容。
- 手机优先显示启动操作，大尺寸竖屏优先显示连接与语音设置；设置可折叠，Redis 输入提供明确标签和错误定位。
- 更新应用图标、通知图标及状态反馈样式，保留 Edge、百度、腾讯云和 Android 系统 TTS 选项。

## 可问内容

1. 车速，例如“车速多少”“现在跑多快”。
2. 电量，例如“电量多少”“SOC 多少”。
3. 障碍物，例如“障碍物情况”“最近障碍物”。
4. 协同模块，例如“协同模块状态”“SAM 反馈”。缺少 `scene_id` 时不判断 V2V/V2I。
5. 规划轨迹点，例如“规划轨迹有多少点”“轨迹点”。
6. 红绿灯，例如“红绿灯什么状态”“信号灯”。只有时间戳时会明确说明业务数据不可用。
