# 渝行智声 v1.2

发布日期：2026-08-25

## 软件信息

- 软件全称：渝行智声车载离线语音交互软件
- 版本号：v1.2（versionCode 12）
- Android 包名：`cn.edu.chd.yuxingvoice`

## 本版调整

- APK 内置 sherpa-onnx 1.13.6、`vits-icefall-zh-aishell3` 中文模型及文本规范化文件，不再要求设备安装系统 TTS 或中文语音包。
- 播报按“内置离线 TTS → Android 系统 TTS → 固定 WAV 故障提示”自动回退，失败后在当前服务会话停用故障后端。
- 唤醒确认“我在”使用内置固定 WAV，缩短首次模型加载前的响应时间。
- 播报期间暂停麦克风采集，结束后恢复并重置 KWS/VAD，避免扬声器回声被再次识别。
- 补齐 V2X、Redis、SOC、RTK、TPMS 等工程词的中文离线模型读法。
- 增加内置模型哈希、回退顺序、固定提示音、TTS 服务声明和半双工链路测试。
