# 渝行智声 v1.4

发布日期：2026-08-25

## 软件信息

- 软件全称：渝行智声车载语音交互软件
- 版本号：v1.4（versionCode 14）
- Android 包名：`cn.edu.chd.yuxingvoice`

## 本版调整

- 删除在 RK3588S 目标平板上效果不达标的 Kokoro/sherpa 本地 TTS 模型与运行库，保留离线 Vosk ASR。
- 新增 Edge、百度和腾讯云三种在线 TTS，并保留 Android 系统 TTS 选项。
- Edge 默认使用 `zh-CN-XiaoxiaoNeural`，支持中英混合文本，无需账号或 API Key。
- 百度和腾讯云使用用户自己的 JSON 配置；导入后通过 Android Keystore + AES/GCM 加密保存，真实凭据不进入 APK。
- 在线 TTS 失败时自动尝试系统 TTS；系统也不可用时播放固定故障 WAV。
- 正式界面新增始终可见的“当前播报内容”框。文字在合成前显示，因此完全没有 TTS 时仍可查看回答。
- 用与默认 Edge 相同的晓晓音色重制“我在”和故障提示音，转为 24 kHz 单声道 PCM，并标准化至 −16 LUFS 目标响度。

## 配置与注册

- Edge：无需注册，不需要自建服务器，但浏览器朗读接口不提供 SLA。
- 百度：需要自行创建百度智能云应用并填写 App ID、API Key、Secret Key。
- 腾讯云：需要自行创建访问密钥并填写 SecretId、SecretKey。
- 仓库根目录提供 `tts-config.example.json`。示例占位符必须替换，未使用的供应商段应删除。
