# 渝行智声 v1.3

发布日期：2026-08-25

## 软件信息

- 软件全称：渝行智声车载离线语音交互软件
- 版本号：v1.3（versionCode 13）
- Android 包名：`cn.edu.chd.yuxingvoice`

## 本版调整

- 用 sherpa-onnx 1.13.6 的 `kokoro-int8-multi-lang-v1_1` 替换原 8 kHz VITS 模型；新模型支持中英双语、103 个音色和 24 kHz 输出，默认使用中文女声 `zf_001`（speaker ID 3）。
- 主界面新增“高质量本地语音 / Android 系统语音”选择和试听按钮；首选后端不可用时自动回退另一后端，固定 WAV 继续最终兜底。
- 删除把所有英文逐字母转换成中文音名的逻辑，只保留 V2X、SOC、RTK 等明确工程缩写的定向读法，普通英文原样交给双语模型。
- 对动态合成 PCM 做限幅响度校正；“我在”和故障提示音也用同一 Kokoro 音色重制为 24 kHz，平均响度由约 −34.6 dB 提升到 −17.1 dB。
- 按 sherpa-onnx Android 要求，首次使用时把 eSpeak 数据复制到应用私有目录并写入完成标记，后续直接复用。
- 114 MB ONNX 在源码中以 89 MB gzip 保存、构建时展开，避免超过 GitHub 普通 Git 的 100 MB 单文件限制；APK 中只包含展开后的模型，不重复包含 gzip 或旧 VITS。

## 使用边界

本版针对 PersonalLLMWiki 记录的 USD32 / RK3588S / 8 GB / Android 13 / 32 英寸竖屏设备选型。发布时目标平板未通过 ADB 连接，因此仍需在该平板上验收首次加载耗时、持续播报温升、2×5 W 扬声器音量、中文音色和英文听感。车辆数据查询继续保持只读。
